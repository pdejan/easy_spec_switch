# Easy Spec Switch

**Easy Spec Switch is a lightweight addon for simple specialization and build switching using configurable chat commands.**

Switch specializations or saved builds without opening the specialization UI, clicking through multiple steps, or setting up extra buttons and macros. All it takes is a quick `/` (slash) command configured to your liking.

Open the straightforward configuration panel with **`/ess`**.

![Easy Spec Switch configuration panel](https://raw.githubusercontent.com/pdejan/dejan.ba/refs/heads/main/img/ess.jpg)

## Configuration

- Fully configurable commands for switching specializations.
- Five configurable shortcuts for saved builds, each with a dropdown to select the corresponding build.

## Example commands

Using a Hunter with `mm` configured for Marksmanship, `r` assigned to the **Raid** build, and `m` assigned to the **M+** build:

| Command | Action |
| --- | --- |
| `/mm` | Switch from Beast Mastery to Marksmanship. |
| `/mmr` | Switch to Marksmanship and load the **Raid** build. |
| `/mmm` | While in Marksmanship with the Raid build, switch to the **M+** build. |

Combine the specialization shortcut and saved-build shortcut without spaces. These are examples; configure your own shortcuts with **`/ess`**.
